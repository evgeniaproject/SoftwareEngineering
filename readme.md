Лабораторные работы по программной инженерии.
В репозитории три ветви:

**Diagrams** - материалы лабораторных работ №2-5 по различным диаграммам;
**Prolog** - программа на языке Prolog. Файл программы: 1_lab_Medvedeva.pl;
**main** - описание содержимого репозитория;

Чтобы открыть нужную работу, выберите ветвь Diagrams или Prolog в списке ветвей над файлами, далее будет представлен список всех файлов в данной ветке, в файле readme.md будет описание каждого файла и отношение его к конкретной лабораторной работе.
